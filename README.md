# Anvi Electrical Enterprises Website

GitHub Pages-ready website for Anvi Electrical Enterprises.

## Repository
Use the repository name exactly:

`anvi-electrical-website1`

## Deploy
1. Upload all files to the GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment → Source**, select **GitHub Actions**.
4. GitHub will deploy the site using `.github/workflows/pages.yml`.

The workflow automatically detects the GitHub username and repository name and generates the correct GitHub Pages URL for the canonical URL, sitemap, robots.txt, Open Graph metadata, and LocalBusiness structured data.

No custom domain is required.
